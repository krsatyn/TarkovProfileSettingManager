# Tarkov Profile Manager — Native Folder Edition 4.0

Windows-приложение для хранения и переноса настроек Escape from Tarkov.

## Главное изменение

Экспорт **не создаёт `.eftprofile` или ZIP**. Каждый профиль — это обычная папка с исходными файлами `.ini` и `.json` без изменений. Например:

```text
Tarkov Profiles/
  PvP/
    Graphics.ini
    Controls.json
  Max FPS/
    Graphics.ini
    Controls.json
```

**Важно:** эти имена файлов приведены только как пример — фактически копируются файлы, найденные в выбранной папке настроек игры. Если имя уже занято, добавляется `(2)`, `(3)` и т.д. Перед записью файлы проверяются по SHA-256. Временная папка при ошибке удаляется.

## Быстрый запуск

1. Windows + Python 3.10+.
2. `pip install Pillow`
3. `python tarkov_profile_manager.py`

## Сборка EXE

Запустите `build_exe.bat` (нужен интернет для установки Pillow и PyInstaller). Готовый исполняемый файл: `dist\\TarkovProfileManager.exe`. Код выполняет интеграционные тесты перед сборкой.

## Экспорт/импорт

- **Сохранить:** считывает текущие `.ini`/`.json` игры в локальную библиотеку.
- **Экспорт:** выберите профиль и папку назначения. Приложение создаст внутри неё подпапку с названием профиля и оригинальными файлами настроек.
- **Импорт папки:** выберите папку профиля, содержащую `.ini`/`.json`.
- **Применить:** закройте игру, выберите профиль и примените. До записи создаётся резервная копия.
- **Общая папка:** выберите синхронизируемую локально общую папку Google Drive. Программа создаст подпапку `Tarkov Profiles`. Экспортируемые профили сохраняются отдельными папками; на другом ПК нажмите «Импорт выбранного».

Для работы с Google Drive необходим **Google Drive для компьютера**, доступ к общей папке и её видимость в проводнике Windows. Само приложение не подключается к Google API; доступ по публичной ссылке без локальной папки не поддерживается. Синхронизацию файлов обеспечивает Google Drive.

## Изображения и адаптивность

- Стартовая картинка `assets/splash.png` — исходное первое изображение 1280×914, **без обрезки**, масштабируется с сохранением пропорций и полностью помещается в доступную область.
- `assets/cat.png` — второе исходное изображение со снежным барсом.
- `assets/cat.ico` — иконка EXE.
- Главное окно меняет компоновку при ширине менее 880 px: управление переносится под список профилей; маскот в узком режиме скрыт ради экономии места. Окна можно изменять по размеру.

## Ограничения

- Программа сохраняет лишь обнаруженные файлы `.ini` и `.json` **непосредственно** в указанной папке игры; не переносит учётную запись, прогресс, игровые файлы, настройки, которые хранятся на сервере.
- При облачной синхронизации дождитесь завершения загрузки/скачивания на обоих ПК. Не изменяйте общие файлы параллельно.
- Исполняемый файл Windows должен собираться на Windows. Графический интерфейс на Windows не тестировался в этой среде.
- Старые `.eftprofile` больше не используются; если нужно перенести ранее сохранённый профиль, экспортируйте его из старой версии в исходные файлы или извлеките содержащуюся внутри архива папку `settings` вручную и импортируйте её.
